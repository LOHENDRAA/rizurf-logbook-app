# 07-exploratory-data — generic (non-internship) logbook explorations

## Purpose

Early generic logbook data explorations covering Student/Employee/
Freelancer roles × Daily/Weekly/Monthly/Growth log types. Kept for
lineage, but separate from the internship design.

## What belongs

Only the two generic `Universal_Logbook_Data` workbooks (single
`Universal Logbook` sheet each).

## What does NOT belong

Internship-specific schema work → see `../02-system-design/data-model/`.
These generic workbooks are a different lineage, NOT earlier versions of
the `Logbook_Data_Discussion` series — do not mix them.
