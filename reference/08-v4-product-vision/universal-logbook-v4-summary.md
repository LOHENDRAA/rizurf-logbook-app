# Universal Logbook

## Who Is Involved?

**Primary user:**
Anyone who wants to track and improve their growth.

Examples:
- Student
- Intern
- Employee
- Freelancer
- Entrepreneur
- Learner

**Others are optional:**
Managers, mentors, teachers, colleagues, coaches, or clients may provide feedback, but they do not need to use the system.

---

# End-to-End Workflow

## Daily — Record
**What did I do and learn?**

- Activity
- Learning
- Skills practised
- Challenge — optional
- Evidence — optional

↓

## Weekly — Reflect
**How did this week go?**

- Achievements
- Key learning
- Challenges
- Feedback received
- Skills improved
- Next goal

↓

## Monthly — Review Growth
**How am I improving?**

- Review progress
- Identify patterns
- Recognise strengths
- Find areas to improve
- Review recurring feedback
- Set future focus

↓

## Long Term — Growth Record

The system builds a record of:

**Skills + Learning + Achievements + Feedback + Goals + Evidence**

---

# Core Cycle

**Do → Record → Learn → Reflect → Improve → Repeat**

## Main Purpose

Universal Logbook helps users turn everyday experiences into a clear record of **learning, progress, and personal growth**.
