# 06-document-sources / examples — filled sample and spreadsheet source

## Purpose

Concrete examples of the paper logbook in use: a filled week-1 sample, its
spreadsheet data source, and a diagram mapping spreadsheet columns to form
fields.

## What belongs

Example/filled sources only. The filled sample describes one student's
week-1 orientation; sample values are illustrative and not repeated here.

## What does NOT belong

Blank templates → see `../templates/`.
